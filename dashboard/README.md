# Dashboard

React app. Views (see HLD → Components → React Dashboard, PRD → US-003/004/005/006):

- **Trace Explorer** — search/filter traces, view individual call detail (prompt, completion,
  metadata, evaluation scores)
- **Analytics** — p50/p95/p99 latency, error rate, request volume, token usage, cost over time;
  filterable by time range (24h/7d/30d) and breakdown by model or tag
- **Evaluations** — view evaluation scores per trace
- **Alert configuration** — create/edit alert rules, view alert history
- **Project settings** — API keys, project members and roles

Not implemented yet.
